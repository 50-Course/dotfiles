# Tmux

I use it to manage multiple terminal sessions in one window. It allows me to split my terminal into multiple panes, switch between them easily, and keep my sessions running even when I disconnect.

Just know this:

The core of this thing no hard, (yes that was a pun) but it can be a bit overwhelming at first. There are three major components to tmux: sessions, windows, and panes.

- A session is a collection of windows. You can have multiple sessions running at the same time, and you can switch between them.
- A window is a single terminal instance. You can have multiple windows in a session, and you can switch between them.
- A pane is a subdivision of a window. You can split a window into multiple panes,

# Usage

Download tmux, clone this repo, once everything is installed. Run,

`git clone https://github.com/tmux-plugins/tpm ~/.tmux/plugins/tpm`

and run:

`Ctrl + I or Cmd + I`
